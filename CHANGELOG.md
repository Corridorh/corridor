# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project
adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Typed `VaspRegistryClient` in the router, replacing a hand-built symbol
  invocation that exceeded Soroban's 9-character symbol limit.
- Read-only getters: `router.get_admin`, `router.get_token`,
  `router.get_registry`, `router.is_hash_used`, and `registry.get_admin`.
- Storage-lifetime policy: instance and persistent TTLs are refreshed on every
  live read/write, with shared constants in `travel-rule-common`.
- Compile-time and unit tests for TTL invariants and ABI-stable error codes.
- Contract tests for removed VASPs, non-positive amounts, negative thresholds,
  unauthorized admin calls, and hash consumption.
- TypeScript SDK unit tests for canonical hashing, order independence, hex
  validation, and a fixed digest vector.
- Off-chain service tests for hashing, encryption round-trips, ciphertext
  freshness, and tamper rejection.
- CI workflow covering formatting, clippy, tests, release WASM build, WASM size
  budget, Node builds/tests, and local Markdown links.
- Dependabot configuration for Cargo, npm, and GitHub Actions.
- Issue templates (bug, feature, good first issue), a pull-request template,
  `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, and `CHANGELOG.md`.
- `BUILD-SPEC.md`, `docs/architecture.md`, `docs/DEPLOYMENT.md`, and
  `docs/ROADMAP.md`.
- Deployment-record format and a Testnet template under `deployments/`.
- Committed `Cargo.lock` and both `package-lock.json` files for reproducible
  builds.
- TTL refresh on `router.is_hash_used` and `registry.get_endpoint` reads.

### Changed

- Corrected the initialization security claim. `require_auth` proves the caller
  controls the supplied admin, but it does not prevent a first-caller race;
  deployment docs and the roadmap now require atomic deploy+init.
- `add_vasp`, `remove_vasp`, `transfer_admin`, and `set_threshold` now return
  typed `Result` errors instead of panicking on unauthorized input.
- `remove_vasp` returns `NotFound` when the address was never registered.
- `compliant_transfer` rejects zero and negative amounts with `InvalidAmount`.
- `initialize` on both contracts rejects negative thresholds and requires the
  admin's authorization.
- The router records the metadata commitment **before** moving tokens
  (checks-effects-interactions).
- Crate types are `["cdylib", "rlib"]` so contracts can be used by integration
  tests, and `common` is an `rlib`.
- `hexToBuffer` / `hexToBytes32` now reject non-hex characters, not just the
  wrong length.
- The SDK encodes `Option<BytesN<32>>` the Soroban way (`Void` / inner value)
  instead of a synthetic tagged union.

### Fixed

- The workspace did not compile: `travel-rule-common` was missing the
  `contracterror` import.
- The router used a 13-character `symbol_short!`, which Soroban rejects at
  compile time.
- The router test suite referenced `vasp_registry` without a dev-dependency and
  used `token::Client::mint`, which does not exist (use `StellarAssetClient`).
- The registry tests used `std::panic::catch_unwind` in a `#![no_std]` crate.
- Contract tests could not call the registry because it was `cdylib`-only.
- `Cargo.lock` was git-ignored, so a clean clone resolved
  `ed25519-dalek 3.x` through `soroban-env-host`'s overly broad `>= 2` spec and
  failed to build. The lockfile is now committed and pins `ed25519-dalek` 2.x.
- Test snapshots generated by `soroban-sdk` are ignored instead of polluting the
  working tree.

## [0.1.0] - 2026-07-16

### Added

- Initial router and VASP registry contracts.
- IVMS101-lite metadata payload, canonical hashing, and a reference off-chain
  exchange service.
- TypeScript SDK for building `compliant_transfer` transactions.
